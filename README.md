# 旅先グルメグリ

React Native ExpoとGoogle Maps APIを使用した、レストラン検索・経路案内アプリです。

## 実装済み機能

### 🗺️ マップ機能
- **現在地表示**: GPSを使用してユーザーの現在地を表示
- **レストラン検索**: 周辺のレストランを自動検索・表示
- **インタラクティブマップ**: Google Maps SDKを使用したフル機能マップ

### 🔍 検索機能
- **Places API**: Google Places APIを使用したレストラン検索
- **オートコンプリート**: リアルタイム検索候補表示
- **キーワード検索**: 特定のキーワードでレストラン検索

### 🧭 経路案内機能
- **Routes API**: Google Directions APIを使用した経路計算
- **複数移動手段**: 徒歩・車・公共交通機関での経路案内
- **視覚的経路表示**: マップ上にポリラインで経路を表示
- **距離・時間表示**: 所要時間と距離の表示

### 📍 レストラン情報
- **詳細情報**: レストランの評価・住所・営業時間
- **連絡機能**: 電話・ウェブサイトへの直接アクセス
- **評価表示**: Google Placesの評価・レビュー表示

### 🎨 UI/UX機能
- **レスポンシブUI**: 美しいマテリアルデザイン
- **リアルタイム更新**: 位置情報の自動更新
- **インタラクティブカード**: レストラン情報の横スクロールカード
- **モーダル詳細画面**: レストラン詳細のポップアップ表示

## 使用API

### Google Maps Platform APIs
- **Maps SDK for Android**: Android端末でのマップ表示
- **Maps SDK for iOS**: iOS端末でのマップ表示
- **Places API (New)**: 新世代のレストラン情報・検索機能
- **Routes API (New)**: 新世代の経路計算・案内機能
- **Geocoding API**: 住所⇔座標変換（従来API継続使用）

## 技術スタック

- **React Native**: クロスプラットフォームアプリ開発
- **Expo**: 開発・ビルド環境
- **TypeScript**: 型安全な開発
- **Google Maps Services**: Google APIのJavaScriptクライアント
- **React Native Maps**: ネイティブマップコンポーネント

## セットアップ・実行

1. **依存関係のインストール**
```bash
npm install
```

2. **Expo開発サーバー起動**
```bash
npx expo start
```

3. **Android実行**
```bash
npx expo run:android
```

4. **iOS実行**
```bash
npx expo run:ios
```

## 主要機能の使い方

### 1. レストラン検索
- 上部の検索バーで場所やレストラン名を検索
- 周辺のレストランが自動的にマップに表示される

### 2. レストラン詳細表示
- マップ上のマーカーをタップ
- 下部のカードをタップ
- 詳細モーダルで評価・営業時間・連絡先を確認

### 3. 経路案内
- レストラン詳細画面で「経路案内」ボタンをタップ
- マップ上に青いルートが表示される
- 距離・所要時間が表示される

### 4. 連絡・アクセス
- 詳細画面から直接電話をかける
- ウェブサイトにアクセス
- 営業時間を確認

## API設定

`.env`ファイルとapp.jsonにGoogle Maps APIキーが設定済みです。
本番環境では適切なAPI制限・課金設定を行ってください。
